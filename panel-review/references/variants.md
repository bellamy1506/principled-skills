# Variants

Use these only when the owner asks for them or the subject clearly calls for
one. The default panel is three lenses, one round, one synthesis.

## Graded rubric

The first panels graded a subject from A+ to F in fixed categories.

- Give all reviewers the same categories and the same scale.
- Ask for a grade per category and a composite, each with a reason.
- The same grade from far-apart lenses is strong evidence about the subject.
  The same grades with different composites mean the lenses disagree on
  what matters; use that in the synthesis.
- For repeat rounds use fresh reviewers and the identical brief, so the
  scores compare. Set a target and a round cap before round one. Stop at
  the target, at the cap, or at a plateau (scores flat, each round naming
  only new small items).

A grade is a measurement. It does not replace the synthesis.

## Research, then resume

Used once for a five-lens targeting panel.

1. Round one ends with each reviewer requesting at most three research
   documents.
2. The orchestrator produces them (facts and sources; no ranking).
3. Each reviewer is resumed with its documents and finishes its report.

The reviewers do not see each other's reports here. It is one round with a
pause, not a cross-pollination round.

## Panel before a build

A panel can choose targets or screen proposals before a larger build effort
(a council, a refactor). The synthesis says what to build and why; the build
is a separate instrument with its own rules. Do not give a panelist the
build.

## Disjoint panels at once

Several panels can run at the same time when their subjects are explicitly
disjoint. Keep each panel's three reviewers concurrent with each other.

## A mechanical pre-step

Many audit findings have the shape "this check would not fire". If the
project can make known mistakes on purpose and see which checks catch them,
run that first and give the panel only the survivors.
